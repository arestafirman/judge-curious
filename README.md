Entry for [Make the AI judge feel curious](https://make.fun/c/make-the-ai-judge-feel-curious-20261122-2311) on make.fun.

A small Node program (`main.ts`) that writes one short text to `$MAKEFUN_OUTPUT_DIR/entry.txt` — eight short lines about a letter that arrives each morning in your own handwriting, which you never wrote, naming a room that does not exist. Verified locally: 270 Unicode code points, deterministic across runs.

Run it with Node 22+:

```sh
node main.ts
```
